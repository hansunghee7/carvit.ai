Carvit UX MCP

회사의 UX 가이드를 AI 코딩 도구에 연결합니다. 도구가 필요한 절을 찾아 읽고 쓴 기록을 남깁니다.

AI 도구가 받는 것.

호출할 수 있는 도구는 다섯 가지입니다.

  • lookup 주제에 맞는 절을 몇 개 찾아 본문과 함께 돌려줍니다.
  • get_section 절 번호로 한 절을 읽습니다.
  • list_sections 검색이 비었을 때 전체 절 목록을 봅니다.
  • cite 절을 근거로 작업을 고쳤다는 기록을 한 줄 이유와 함께 남깁니다.
  • usage 조회·인용·찾지 못한 검색의 수를 날짜별, 사람별로 셉니다.

연결하기.

아래 명령어를 터미널에 붙여 넣습니다. 주소와 비밀키는 가입 메일로 받습니다.

claude mcp add --transport http carvit <주소> --scope user --header "Authorization: Bearer <회사 코드>:<비밀키>"

하지 못하는 것.

검색은 의미가 아니라 절 제목과 본문의 단어가 맞는지로 찾습니다. 맞는 절이 없으면 빈 결과가 나오고, 그 검색은 찾지 못한 검색으로 기록되며, 전체 목록을 보는 쪽으로 넘어갑니다.

이미 연결했나요?

로그인하면 사용 기록, 가이드, 연결 방법을 볼 수 있습니다.
