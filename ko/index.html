AI로 화면을 만드는 가장 정확한 방법

만들기 전에 가이드부터 찾습니다

화면을 만들기 직전에 AI가 할 일을 그대로 묻고, Carvit이 맞는 절을 찾아 돌려줍니다. 사람이 가이드를 찾아 건네지 않아도, 매번 같은 기준으로 시작합니다.

carvit · lookup
query = "결제 확인 버튼 순서"

→ 1.38 확인 창은 결과를 말하고, 버튼은 [취소] [주 동작] 순서로
→ 1.12 주 동작과 보조 동작은 시각적 크기로 구분한다
→ 1.7 버튼 라벨은 동사와 결과로 쓴다

값.confirm-actions{ justify-content:flex-end; gap:8px }
값.btn.primary{ background:var(--primary) }

값까지 그대로 가져다 씁니다

절에는 규칙과 함께 색, 여백, 둥글기, 문구 같은 실제 값이 들어 있습니다. AI는 짐작하지 않고 그 값으로 만들고, 가이드에 없는 결정은 새 절로 넣자고 먼저 묻습니다.

carvit · draft_screen
:root{
  --primary: #171717;
  --background: #ffffff;
  --destructive: #e7000b;
  --radius: 10px;
}

.confirm-actions{
  justify-content: flex-end;
  gap: 8px; 1.38
}
