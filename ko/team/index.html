Carvit를 만드는 사람과 AI 에이전트

창업자 한 명과 일곱 AI 에이전트가 영상, 인프라, 제품, 개발, 글, 코드 검토를 나눠 맡습니다.

Founder

사이먼

  • Carvit를 만든 창업자입니다.
  • 빗썸 COO, 요기요 CPO, 삼성전자 PM, 네이버 콘텐츠 서비스 팀장을 지냈습니다.
  • 25년 경력으로 300곳이 넘는 스타트업을 코칭했습니다.
  • 직접 쓰려고 AI 에이전트 팀과 함께 Carvit를 만듭니다.
  • 제품과 방향에 관한 결정은 직접 내립니다.

AI 에이전트

영상 에이전트

핏

  • 대본, 음성, 영상 컷, 조립, 예약까지 이어서 맡아 여러 채널에 올립니다.
  • 파일과 로그로 확인한 결과만 완료라고 보고하고, 막히면 원인을 기록해 다시 시도합니다.
  • 영상 33편 제작, 22편 공개(8/28~10/14 기준)
  • 요청과 회신은 메시지로 주고받고, 정한 결정은 공정 카드에 남겨 다음 세션이 이어받습니다.
  • 사장님은 주제, 음성, 조립본 세 곳만 확인하고 나머지는 자동으로 진행합니다.

인프라 에이전트

탐

  • 배포, 크레딧, 감시 같은 인프라를 돌보고 운영을 챙깁니다.
  • 막힌 곳은 멈추지 않고 해결 경로를 찾아 만듭니다.
  • 반복 업무는 스크립트와 로컬 모델에 맡기고, 판단과 지휘에 집중합니다.
  • 회사 저장소 병합 PR 2,196건(8/29 이후, 2026-10-14 기준), Carvit Pass를 만들었습니다.
  • 다른 에이전트와는 PR 댓글과 우편으로 소통하고, 결정은 기록으로 남깁니다.

제품 에이전트

지투

  • 제품이 고객에게 쓰이는 모습을 살피고 가이드를 가꿉니다.
  • 가이드는 근거가 있는 절만 남기고, 쓰인 기록을 남겨 다음 개선의 근거로 삼습니다.
  • 고객이 만든 화면이 가이드와 어긋나는 곳을 찾아 고칩니다.
  • 병합 PR 65건(9/26~10/14), 데모 고객 가이드 2건을 만들었습니다.
  • 사장님과는 결정할 것만 한 장으로 요약해 주고받습니다.

개발 에이전트

노트

  • Carvit 가이드 서버와 연결 도구, 가입·로그인을 만들고 배포합니다.
  • 시험과 실제 서버 응답으로 확인한 것만 완료로 보고합니다.
  • 운영 DB는 대상을 먼저 확인하고, 승인받은 범위 안에서만 바꿉니다.
  • 서버 저장소 병합 PR 612건(9/6 이후, 2026-10-14 기준)을 배포했습니다.
  • 서버 코드는 지투의 검토를 거쳐 병합합니다.

글 에이전트

마야

  • 사장님의 경험과 일의 기록을 글로 써서 블로그와 SNS에 발행합니다.
  • 글마다 사장님이 직접 겪은 장면을 근거로 쓰고, 증명하지 못하는 말은 쓰지 않습니다.
  • 주제 후보, 초안, 글쓰기 검사, 새 호출 평가, 사장님 확인 순서로 쓰고 이미지도 확인한 뒤 예약합니다.
  • 2026-10-14 기준 예약한 SNS 글 13건, 공정 카드 47개를 쌓았고 9/24부터 자동 발행합니다.
  • 지투와는 Carvit 문구를, 탐과는 게시물 성과 수집을 맞춰 일합니다.

코드 검토 에이전트

덱스

  • 코덱스 모델로서 코드 변경을 병합 전에 검토합니다.
  • 출처가 있는 사실을 근거로 변경이 의도와 맞는지 짚습니다.
  • 같은 편이 쓴 코드를 같은 눈으로 보지 않도록 독립된 눈으로 봅니다.
  • 근거 없는 지적은 하지 않고 확인한 것만 말합니다.
  • 검토 의견은 기록으로 남겨 쓴 쪽이 바로 고칠 수 있게 합니다.

코드 검토 에이전트

비티

  • 안티그래비티 모델로서 코드 변경을 병합 전에 검토합니다.
  • 변경이 만들 수 있는 위험과 다른 방법을 함께 짚습니다.
  • 쓴 쪽이 놓치기 쉬운 가정과 예외를 먼저 묻습니다.
  • 코드의 논리와 보안, 위험 요소를 점검해 결과를 알립니다.
  • 최종 판단은 쓴 쪽과 사장님이 내리고, 검토는 그 판단의 재료가 됩니다.
