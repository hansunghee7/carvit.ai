적용 범위

이 방침은 Carvit 웹사이트(carvit.ai), Carvit UX MCP 서비스, 그리고 Carvit 운영자가 본인의 유튜브 채널 분석 수치를 읽는 데 쓰는 내부 도구 Carvit Insight에 적용됩니다.

다루는 정보

Carvit UX MCP: 가입할 때 입력한 이메일 주소와 회사 이름, 회사가 서비스에 저장한 UX 가이드 본문, 사용 기록(어느 가이드 절을 언제 조회·인용했는지). Carvit Insight: 운영자 본인 유튜브 채널의 조회 전용 분석 수치(조회수, 시청 유지율, 구독자 증감 등)와 그 채널 영상의 공개 댓글. 다른 사람의 구글 계정 데이터는 수집하지 않습니다.

구글 사용자 데이터

Carvit Insight는 운영자 본인의 유튜브 분석 데이터를 읽기 전용으로만 요청합니다. 이 데이터는 운영자 본인 영상의 성과를 재고 다음 발행을 정하는 데에만 씁니다. 판매하지 않고, 제3자와 공유하지 않으며, 광고에 쓰지 않고, AI 모델을 학습시키는 데 쓰지 않습니다. 수치의 요약은 운영자가 본인 채널 성과를 분석하려고 쓰는 AI 어시스턴트에게 보여 줄 수 있습니다. Carvit Insight가 구글 API로 받은 정보를 쓰고 전달하는 방식은 한정 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

저장 위치

계정·사용 기록은 Carvit을 운영하는 서비스 제공업체(클라우드 호스팅, 데이터베이스, 이메일 발송)에 저장됩니다. Carvit Insight의 구글 API 데이터는 운영자만 접근할 수 있는 비공개 저장소에 보관합니다.

공유

개인정보를 판매하지 않습니다. Carvit을 운영하는 데 필요한 서비스 제공업체와, 법이 요구하는 경우에만 공유합니다.

보관과 삭제

계정 정보는 계정이 유지되는 동안 보관합니다. 계정 정보 삭제를 요청할 수 있고, 운영자는 보관 중인 구글 API 데이터를 지우고 https://myaccount.google.com/permissions 에서 언제든 접근 권한을 해제할 수 있습니다.
