Privacy Policy

Last updated: 2026-10-13

Who this covers

This policy covers the Carvit website (carvit.ai), the Carvit MCP service, and an internal tool named Carvit Insight that Carvit's operator uses to read the operator's own YouTube channel analytics.

What we handle

Carvit MCP: the email address and company name you sign up with, the UX guide text a company stores in the service, usage records (which guide sections were viewed or cited, and when), and the questions you send to the connection helper and the answers you get (text that looks like an email, phone number, install code, or key is hidden). Carvit Insight: read-only analytics numbers of the operator's own YouTube channel, such as views, watch-time retention, and subscriber changes, plus public comments on that channel's videos. We do not collect any other person's Google account data.

Google user data

Carvit Insight asks for read-only access to the operator's own YouTube analytics. We use that data only to measure how the operator's own videos perform and to decide what to publish next. We do not sell it, share it with third parties, or use it for advertising. We do not use it to train AI models. Summaries of the numbers may be shown to AI assistants the operator uses to analyze the operator's own channel performance. Carvit Insight's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Connection helper (Ask Jitu)

When a signed-in user sends a question to the connection helper, Carvit sends that question to Claude from Anthropic to write the answer. Before sending, Carvit hides text that looks like an email, phone number, install code, or key. Carvit uses Anthropic with its data retention and training options turned off. Questions and answers are kept for 90 days so Carvit can improve its guidance and answer you directly, then deleted. Carvit does not use them for advertising or to train models. Please do not write names, addresses, passwords, or keys in your question.

Website visit analytics

carvit.ai uses Microsoft Clarity to record clicks, scrolling, and page movement so we can see where visitors get stuck and fix it. Text typed into fields is masked and not recorded, and a cookie links visits from the same browser. We use these records only to improve the site and do not sell them or use them for ads. Microsoft explains its processing at https://privacy.microsoft.com.

Where data is stored

Account and usage data are stored with the service providers that run Carvit (cloud hosting, database, and email delivery). Google API data from Carvit Insight is stored in a private repository that only the operator can access.

Operator access and edits

To provide support and resolve problems, a Carvit operator may view or edit a customer's UX guide. Access records (who, when, which document) are kept for 90 days, and edits appear in the version history as "Operator (Carvit support)".

Sharing

We do not sell personal data. We share it only with the service providers needed to run Carvit (including Anthropic, which writes the connection helper answers), or when the law requires it.

Retention and deletion

We keep account data while the account is active. You can ask us to delete your account data, and the operator can delete the stored Google API data and revoke access at any time at https://myaccount.google.com/permissions.

Contact

Questions or deletion requests: tam@carvit.ai.
