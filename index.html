Guides get written, then nobody opens them.

A UX guide in a document works only if someone remembers to read it at the right moment. An AI tool that builds a screen will not open it unless something puts the right section in front of it.

The AI asks. The guide answers. The use is logged.

Carvit UX MCP is an MCP server your AI tool connects to. It finds the sections that match the task, returns them with their values, and records which section was used and why.

Example from our own guide

askquery="header login menu"

answer1.39 Header menu: logo on the left, menu and login on the right

recordsection 1.39, note="built the header from 1.39"

answerrecorded
