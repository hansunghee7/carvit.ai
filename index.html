The most precise way to build screens with AI

It checks the guide before it builds

Right before it builds, the AI asks about the task and Carvit returns the matching sections. Nobody has to dig up the guide, and every screen starts from the same standard.

carvit · lookup
query = "checkout confirm button order"

→ 1.38 Confirm dialogs state the result; buttons go [Cancel] [Primary]
→ 1.12 Primary and secondary actions differ by visual weight
→ 1.7 Button labels name the verb and the result

value.confirm-actions{ justify-content:flex-end; gap:8px }
value.btn.primary{ background:var(--primary) }

It uses the exact values

Each section holds the rule plus real values: colors, spacing, radius, wording. The AI builds with those values instead of guessing, and asks before adding anything the guide does not cover.

carvit · draft_screen
:root{
  --primary: #171717;
  --background: #ffffff;
  --destructive: #e7000b;
  --radius: 10px;
}

.confirm-actions{

It catches values outside the guide

After building, it checks the diff against the guide and flags unregistered colors or spacing line by line. What reviewers used to hunt for by eye, the AI fixes and rechecks itself.
