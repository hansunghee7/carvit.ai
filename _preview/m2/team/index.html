The people and AI agents building Carvit

The founder and seven AI agents split roles across video, infrastructure, product, development, writing, and code review.

Founder

Simon

  • Founder who built Carvit.
  • Former Bithumb COO, Yogiyo CPO, Samsung Electronics PM, and Naver Content Services Team Lead.
  • With 25 years of experience, has coached more than 300 startups.
  • We build Carvit with an AI agent team to use it ourselves.
  • We make product and direction decisions ourselves.

AI Agent

Video Agent

Fit

  • Handles scripts, audio, video cuts, assembly, and scheduling in sequence to publish across multiple channels.
  • Reports complete only for results verified by files and logs, and records the cause to retry if stuck.
  • 33 videos produced, 22 published (as of 8/28~10/14)
  • Exchanges requests and replies by message, and records decisions on process cards for the next session to take over.
  • The founder checks only three parts: topic, voice, and assembled cut, while the rest proceeds automatically.

Infrastructure Agent

Tam

  • Manages infrastructure such as deployments, credits, and monitoring, handling day-to-day operations.
  • Instead of stopping when blocked, finds a resolution path and builds it.
  • Leaves repetitive tasks to scripts and local models, focusing on judgment and direction.
  • Built Carvit Pass and merged 2,196 PRs in company repositories (since 8/29, as of 2026-10-14).
  • Communicates with other agents through PR comments and mail, leaving decisions as records.

Product Agent

Jitu

  • Monitors how customers use the product and manages guides.
  • Keeps only sections supported by evidence in guides, and leaves written records as the basis for future improvements.
  • Finds and fixes friction points on screens used by customers.
  • Merged 65 PRs (9/26~10/14) and created 2 demo customer guides.
  • Summarizes only decision items into a single page to share with the founder.

Development Agent

Note

  • Builds and deploys the Carvit guide server, connection tools, sign-up, and log-in.
  • Reports complete only for items verified by tests and actual server responses.
  • Verifies the target first for production DBs and makes changes only within the approved scope.
  • Deployed 612 merged PRs in the server repository (since 9/6, as of 2026-10-14).
  • Merges server code after review by Jitu.

Writing Agent

Maya

  • Writes posts based on the founder's experiences and work records, publishing them on blogs and social media.
  • Bases every article on scenes the founder experienced directly, and avoids unproven statements.
  • Writes in the order of topic candidates, draft, style check, independent evaluation, and founder approval, then schedules posts after verifying images.
  • As of 2026-10-14, scheduled 13 social media posts and accumulated 47 process cards, publishing automatically since 9/24.
  • Aligns with Jitu on Carvit copy and with Tam on collecting post performance.

Code Review Agent

Dex

  • As a Codex model, reviews code changes before merging.
  • Checks whether changes match intent based on sourced facts.
  • Being a different model from the one that wrote the code, it does not miss the same mistakes.
  • Avoids baseless comments and states only what has been verified.
  • Leaves review comments as records so the author can fix them right away.

Code Review Agent

BT

  • As a model running in Antigravity, reviews code changes before merging.
  • Points out risks that changes might introduce along with alternative approaches.
  • First asks about assumptions and exceptions that the author might easily miss.
  • Checks code logic and security, then reports the results.
  • The author and founder make the final call, and reviews serve as input for that decision.
