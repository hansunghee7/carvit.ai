The people and AI agents who build Carvit

One founder and seven AI agents split the work across video, infrastructure, product, development, writing and code review.

Founder

Simon

  • Founder who built Carvit.
  • Former COO at Bithumb, CPO at Yogiyo, PM at Samsung Electronics, and content service team lead at Naver.
  • Coached more than 300 startups over a 25-year career.
  • Builds Carvit together with a team of AI agents, because he uses it himself.
  • Makes the decisions on product and direction himself.

AI agents

Video agent

Fit

  • Handles scripts, voice, video cuts, assembly and scheduling end to end, and publishes to multiple channels.
  • Reports only results confirmed by files and logs as done; when blocked, records the cause and tries again.
  • 33 videos produced, 22 published (Aug 28 to Oct 14)
  • Requests and replies go by message, and decisions are kept on process cards so the next session can pick up.
  • The founder checks only three points, topic, voice and the assembled cut, and everything else runs automatically.

Infrastructure agent

Tam

  • Looks after infrastructure such as deployment, credits and monitoring, and keeps operations running.
  • Does not stop when blocked; finds and builds a way through.
  • Hands repeat work to scripts and local models and focuses on judgment and direction.
  • 2,196 merged PRs in the company repository (since Aug 29, as of 2026-10-14); built Carvit Pass.
  • Talks with other agents through PR comments and mail, and keeps decisions on record.

Product agent

Jitu

  • Watches how the product is used by customers and tends the guide.
  • Keeps only sections that have a basis, and uses the record of how they are used as grounds for the next improvement.
  • Finds where customer-built screens drift from the guide and fixes them.
  • 65 merged PRs (Sep 26 to Oct 14); made 2 demo customer guides.
  • With the founder, trades one-page summaries of only the decisions to make.

Engineering agent

Note

  • Builds and deploys Carvit's guide server, connection tools, sign-up and login.
  • Reports done only what was confirmed by tests and real server responses.
  • For the production database, checks the target first and changes it only within the approved scope.
  • Deployed 612 merged PRs in the server repository (since Sep 6, as of 2026-10-14).
  • Merges server code after Jitu's review.

Writing agent

Maya

  • Turns the founder's experience and work records into posts and publishes them to the blog and social media.
  • Writes each post from a scene the founder lived through, and never writes claims that cannot be proven.
  • Works in order: topic candidates, draft, writing check, new-reader evaluation, founder check; checks images too, then schedules.
  • As of 2026-10-14, 13 social posts scheduled and 47 process cards built; auto-publishing since Sep 24.
  • Aligns Carvit copy with Jitu and post performance collection with Tam.

Code review agent

Dex

  • As a Codex model, reviews code changes before they are merged.
  • Checks, based on facts with sources, whether a change matches its intent.
  • Looks with independent eyes so that code is not read by the same eyes that wrote it.
  • Makes no unfounded remarks and says only what it has confirmed.
  • Leaves review comments on record so the author can fix them right away.

Code review agent

BT

  • As an Antigravity model, reviews code changes before they are merged.
  • Points out the risks a change could create and the alternatives.
  • Asks first about the assumptions and exceptions the author is likely to miss.
  • Checks the logic, security and risk factors of the code and reports the result.
  • The final call is made by the author and the founder; the review is material for that call.
