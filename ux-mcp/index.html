Carvit UX MCP

Connect your company's UX guide to AI coding tools so every screen starts from the same standard. Each section (guide item) it used is recorded, and your team can check it.

Connect it.

Pick your tool and connect. After you sign in, use [Copy] on the Connect screen to get your address and install code. The commands below only show the shape and will not run as written.

Paste it into the Claude Code chat or your terminal and press Enter.

claude mcp add --transport http carvit <address> --scope user --header "Authorization: Bearer <company code>:<install code>"

Connect in three steps from a terminal. First save your company code and install code, joined by a colon, in an environment variable.

macOS and Linux

export CARVIT_MCP_TOKEN="<company code>:<install code>"

Windows PowerShell (applies from a new window)

setx CARVIT_MCP_TOKEN "<company code>:<install code>"

Then register the server in Codex

codex mcp add carvit --url <address> --bearer-token-env-var CARVIT_MCP_TOKEN

If carvit appears in codex mcp list, you are done.

Paste this sentence into the AI input box and the tool sets up the connection for you. If it asks to edit a settings file, allow it.

Check that it worked

In Claude Code, run the command below. If carvit shows as Connected, you are done. In Codex, use codex mcp list above. In other tools, look for carvit in that tool's MCP list.

claude mcp list

If it is not Connected, copy the address and install code again from the Connect screen and connect again the same way.

Add your guide.

Once connected, adding your guide takes three steps.

  1. Get a document ready. DESIGN.md, a design doc, screenshots, a website address or existing style code all work. With no document, pick a starter template in the UX Guide tab after you log in.
  2. Attach the document or paste its link in your AI tool and say "Upload this to Carvit UX."
  3. Check the uploaded guide in the UX Guide tab. If you are not an editor, the AI sends your change as a proposal, and the guide stays as it is until an editor approves.

What it looks like.

Once connected, just talk as usual. This is an example conversation; the sections it finds depend on your company's guide.

You  Add a save button to the settings screen. Follow our company UX guide.
AI   (lookup) Found 2 sections (guide items) about buttons. Built it with one primary button per screen, as the section says.
AI   (cite) Recorded the section I used, with a one-line reason.

What you can do once connected.

The main things. The name in brackets is the tool your AI calls.

  • Find the right guide sections (lookup): finds up to a few sections for a topic and returns their text.
  • Read one section exactly (get_section): reads one section by its number.
  • See the full contents (list_sections): lists every section, for when a search finds nothing.
  • Record the reason (cite): records that a section changed the work, with a one-line reason.
  • See usage (usage): counts lookups (how often the guide was searched), citations (how often a reason was left) and searches that found nothing, by day and by person.

What it does not do.

Search matches words in section titles and text, not meaning. When nothing matches, the answer is empty, the search is recorded as a miss, and the full section list is the fallback. If the section you want does not come up, ask again using words from its title.

Questions.

Quick answers for people connecting for the first time.

How do I send feedback to the Carvit team?

Tell your AI tool: "Send feedback to the Carvit team." Complaints, feature requests and thanks all work. The tool tidies what you said and passes it to the team through the feedback tool.

If you want a reply, also tell it how to reach you, such as an email address. Without that, the feedback arrives but we cannot answer.

You can also let your AI tool send feedback by itself when it gets stuck: ask it to call feedback, with four parts (which screen, what it was trying to do, what blocked it, the exact words it saw), one topic per note.

Do not paste install codes, passwords, customer names or private business details. Describe the problem in general words.

I just connected. How do I see what I can do?

Say "Show Carvit help" to your AI tool, or run /carvit:help in Claude Code. It lists what you can do by number: build a guide, update it, view it, build a service with MCP, invite teammates, and send feedback.

How do I change my guide later, and what if I change it by mistake?

Change: describe the change, for example "Make the main button color #0F766E". The AI finds the related section and shows how it will look, and the change goes live when you say "upload it". If you did not mean it, say "Go back to the previous version" and every version can be restored.

Only an editor (assigned by the owner) can change the guide directly. If you are not an editor, the AI sends your change as a proposal, and the guide stays as it is until an editor approves.

For the first upload, see the three steps under "Add your guide" above.

Where do I choose one of the UX templates Carvit provides?

Two places. After you log in, open the "UX Guide" tab to pick a starting template on screen. Or tell your AI tool "Create it from a starting template" and it will list the choices.

There are six: shadcn default (clean basics), brand site (content and brand), Instagram style (photos and feeds), grid console (tables and admin screens), Carvit (tidy black and white), and studio (cream background, for internal tools and reports). Start from the closest one and adjust it to your company.
